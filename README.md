# Personal Finance Manager

A simple C# console application for managing personal income, expenses, and monthly budgets.

## Features

- Add income transactions.
- Record expense transactions.
- View all transactions.
- Calculate total income and expenses.
- Check current account balance.
- Set a monthly budget.
- View a financial summary.
- Generate random financial tips.

## Technologies

- C#
- .NET
- Visual Studio Code

## Concepts Practised

This project demonstrates practical application of:

- Variables and data types
- Conditional statements and switch
- Loops (`for`, `foreach`, `while`, `do-while`)
- Arrays
- Methods and parameters
- Input validation and type conversion
- String interpolation and formatting
- Decimal arithmetic
- Random number generation

## Getting Started

### Prerequisites

- .NET SDK installed.
- Visual Studio Code or another C# editor.

### Run the application

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

Run the application:

```bash
dotnet run
```
